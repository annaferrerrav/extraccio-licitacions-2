Resum per concurs

Una fila per expedient amb la seva valoració. OK = tot coincideix · Revisar = imports i files quadren però hi ha diferències en camps descriptius (descripció, referència, model, marca, expedient) · KO = falten/sobren files o difereixen proveïdor, lot, quantitat, preus, import o estat. Clica una fila per filtrar la resta de l'anàlisi a aquell concurs.

Files per proveïdor

Nombre de línies de cada proveïdor, dins les carpetes presents a l'extracció.

Import per lot / proveïdor

Suma de l'import total sense IVA agrupat per carpeta i lot, o per carpeta i proveïdor.

Fila per fila

Una carpeta per bloc. Cada fila mostra el valor de l'extracció (superior) i el de la resposta correcta (inferior); vermell = no coincideix.
